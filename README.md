# Image Processing Retina

Project Pengolahan Citra Digital menggunakan dataset DRIVE.

## Tugas 1

Implementasi operasi dasar pengolahan citra:

1. Citra negatif
2. RGB ke grayscale
3. Image brightening
4. Operasi aritmetika dua citra
5. Operasi geometri
   - Translasi
   - Rotasi
   - Flipping
   - Zooming
